THE BIG PICTURE

What is HTTP?

HTTP stands for Hypertext Transfer Protocol. It defines how web browsers request information and how web servers respond.

From loading a photograph to retrieving application data, HTTP supports many everyday interactions on the Web. This project explores those exchanges and the changes introduced across HTTP versions.
