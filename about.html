About This Project

This website was created for IT 3203 at Kennesaw State University. It builds on my research presentation, HTTP and Its Evolution, by presenting the information across connected webpages.

The project explores how HTTP works, how its versions have changed, and the key concepts behind web communication. It also demonstrates HTML page structure and CSS styling.

This website is a class project for IT 3203 at Kennesaw State University.
