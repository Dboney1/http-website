The Client and Server

HTTP follows a client-server model. The client, such as a web browser, requests a resource. The server processes the request and sends a response. Resources can include webpages, images, videos, or data.

The Request and Response Process

  1. A user enters a URL or selects a link.
  2. The browser locates and connects to the server.
  3. The browser sends an HTTP request.
  4. The server processes the request and returns a response.
  5. The browser uses the response to display content.

Common HTTP Methods

  • GET: Requests a resource.
  • POST: Submits data for processing.
  • PUT: Creates or replaces a resource at a specified address.
  • DELETE: Requests the removal of a resource.

HTTP Status Codes

A response includes a status code that describes the result of the request.

  • 200 OK: The request succeeded.
  • 301 Moved Permanently: The resource has a new address.
  • 404 Not Found: The resource could not be found.
  • 500 Internal Server Error: The server encountered an unexpected problem.
