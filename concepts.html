Key Concepts

Seven important terms for understanding HTTP.

Home How HTTP Works HTTP’s Evolution Key Concepts References About

1. Client

A client is an application that requests resources from a server. A web browser is a common example of an HTTP client.

2. Server

A server receives requests and returns responses. It can provide webpages, images, files, or application data.

3. URL

A Uniform Resource Locator, or URL, identifies where a resource can be accessed. It can include a scheme, host name, path, and query parameters.

Example: https://example.org/learn/http?unit=1

4. Request

An HTTP request is a message sent by a client to a server. It includes a method, a request target, headers, and sometimes a body containing data.

5. Response

An HTTP response is the server’s reply to a request. It includes a status code, headers, and sometimes a body containing the requested content or error information.

6. Caching

Caching stores copies of resources for reuse. When caching rules allow it, a browser can reuse stored content instead of downloading it again, reducing loading time and network use.

7. HTTPS

HTTPS protects HTTP communication using TLS. It encrypts data in transit, helps detect changes to that data, and allows the browser to verify the server’s identity. HTTPS does not guarantee that a website’s content is trustworthy.
